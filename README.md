
# Simple Calculator Web App

## Live Demo
https://calculator-project-zeta-orpin.vercel.app/

## Description
A responsive calculator web application built using HTML,
CSS, and JavaScript as part of a Web Development Internship.

## Features
- Addition, subtraction, multiplication, and division
- Decimal number support
- Correct arithmetic operator precedence
- Clear All (AC) and Delete (DEL) buttons
- Orange equals button with a black theme
- Keyboard support
- Division-by-zero error handling
- Responsive layout for mobile and desktop
- JavaScript functions documented with comments

## Technologies
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html: Calculator interface
- css/style.css: Calculator styling
- js/script.js: Calculation logic and event handling
- README.md: Project documentation

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in a browser or use Live Server.
3. Enter calculations using the buttons or keyboard.

## Keyboard Shortcuts
- 0-9: Enter numbers
- +, -, *, /: Arithmetic operations
- Enter or =: Calculate
- Backspace: Delete the last character
- Escape: Clear the calculator

## Testing
Test basic calculations, decimal numbers, negative numbers,
operator precedence, division by zero, invalid expressions,
and different screen sizes.

## Limitations
This is a front-end calculator. It does not store calculation
history or provide scientific calculator functions.
